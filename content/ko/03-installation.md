# 03. 설치 & 준비

> 공식 도움말과 샘플 그래프를 실행할 수 있는 환경부터 준비합니다.

---

## 준비할 것

- Civil 3D 설치
- Dynamo 실행 위치 확인
- 샘플 그래프 폴더 확인
- Dynamo Player 사용 여부 확인

## 첫 점검

```bash
start civil3d
```

```text
Civil 3D 실행 후 Dynamo 메뉴가 보이는지 확인
```

### 확인할 항목

| 항목 | 확인 내용 |
|---|---|
| Dynamo 메뉴 | 실행 위치 확인 |
| 샘플 그래프 | 파일 열기 가능 여부 |
| Player | 버튼형 실행 가능 여부 |
| 권한 | 파일 읽기/쓰기 가능 여부 |

## 실수 방지

> 처음에는 새 그래프를 만들기보다, **샘플을 열어서 실행해보는 것**이 가장 안전합니다.
