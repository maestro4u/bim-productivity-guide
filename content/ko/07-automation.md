# 07. MCP & 외부 도구 연결

> Civil 3D 밖의 도구와 연결해 업무 범위를 넓히는 방법을 정리합니다.

---

## 연결 대상

- Excel
- Revit
- Navisworks
- ACC
- 파일 서버

## 왜 필요한가요?

반복 설계업무는 Civil 3D 안에서만 끝나지 않습니다. 보고서, 검토, 협업, 배포가 이어집니다.

### 예시

- Excel에서 좌표 읽기
- Revit 모델과 결과 비교
- Navisworks 검토 결과 정리
- ACC 자료를 팀 공유용으로 정리

> **원칙**: 자동화는 한 도구 안에서 끝나는 게 아니라, **도구 사이를 이어주는 것**입니다.
