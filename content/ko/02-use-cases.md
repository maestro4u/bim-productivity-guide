# 02. 2개월차 선형과 종단 설계

> 지형 위에 도로의 기준선을 얹고, 그 기준선에 계획고를 부여하는 단계입니다.

---

## 선형 및 종단 설계

Civil 3D에서 선형과 종단은 도로 설계의 뼈대다.  
선형이 도로의 평면 흐름을 정하고, 종단이 도로의 높이 흐름을 정한다.

1개월차에서 좌표와 지형 기준을 맞췄다면,  
2개월차에서는 그 지형 위에 도로 중심선을 만들고 기존 지반과 계획고를 비교한다.

### 1. 평면 선형을 작성한다

#### 1.1 선형의 역할

`Alignment`는 도로의 중심 기준선이다.  
단순한 CAD 선이 아니라, 이후 종단, 코리더, 횡단, 물량산출이 모두 참조하는 Civil 3D 객체다.

선형 이름은 나중에 찾기 쉽게 작성한다.

예시:

- `ROAD_A_CL`
- `MAIN_ROAD_CENTER`
- `ACCESS_ROAD_01_CL`

`Alignment - (1)` 같은 기본 이름은 사용하지 않는 것이 좋다.  
나중에 종단, 코리더, 횡단을 만들 때 어떤 선형인지 구분하기 어렵다.

#### 1.2 선형 작성 도구 실행

선형은 다음 위치에서 작성한다.

**Home 탭 -> Create Design -> Alignment -> Alignment Creation Tools**

명령어로는 다음을 사용할 수 있다.

**선형작성 : `CREATEALIGNMENTLAYOUT`**

선형을 만들기 전에는 다음을 확인한다.

- 도면 좌표계가 맞는가
- 기존 지형 Surface가 정상 생성되었는가
- 도로 중심선으로 사용할 기준선이 정리되어 있는가

[그림 예정: Alignment Creation Tools 실행 위치와 선형 이름 입력 화면]

### 2. 선형 생성 방식을 이해한다

Civil 3D의 선형은 여러 방식으로 만들 수 있다.  
초보자는 모든 방식을 한 번에 외우기보다, 어떤 상황에서 어떤 방식을 쓰는지 먼저 이해하면 된다.

#### 2.1 폴리라인 변환

기존 CAD 선이 이미 있을 때는 폴리라인을 선형으로 변환할 수 있다.  
초기 검토나 기존 계획선을 Civil 3D 객체로 바꿀 때 유용하다.

다만 최종 설계에서는 선형 생성 도구로 기하조건을 직접 관리하는 것이 좋다.

#### 2.2 Tangent with Curves

입문자 실습에서는 `Tangent with Curves` 방식이 가장 이해하기 쉽다.  
직선을 클릭해 나가면 Civil 3D가 곡선을 포함한 선형을 생성한다.

이 방식은 도로 흐름을 빠르게 잡을 때 좋다.

#### 2.3 고정곡선, 플로팅곡선, 자유곡선

선형 편집에서는 곡선의 성격을 구분해야 한다.

- `Fixed Curve`: 위치나 반경이 고정된 곡선
- `Floating Curve`: 한쪽 기준에 접하면서 조정되는 곡선
- `Free Curve`: 두 선형 요소 사이를 자연스럽게 연결하는 곡선

실무에서는 두 직선 사이를 부드럽게 연결해야 하는 경우가 많으므로 `Free Curve`를 자주 사용한다.

[그림 예정: Fixed, Floating, Free Curve의 차이 개념도]

### 3. KDS 기준을 적용한다

#### 3.1 설계 기준 체크의 의미

도로 선형은 보기 좋게 그리는 선이 아니다.  
설계속도, 최소 곡선반경, 완화곡선, 편경사 기준을 만족해야 한다.

Civil 3D에서는 `Criteria-Based Design` 기능으로 기준 만족 여부를 확인할 수 있다.

#### 3.2 기준 기반 설계 설정

설정 위치는 다음과 같다.

**Alignment Properties -> Design Criteria 탭**

확인할 항목은 다음과 같다.

- `Use criteria-based design` 체크
- 설계속도 입력
- 설계 기준 파일 선택
- 최소 곡선반경 확인
- 기준 미달 경고 아이콘 확인

KDS 44 00 00 기준을 XML 파일로 적용할 수 있다면 가장 좋다.  
다만 교육 단계에서는 먼저 기준 파일을 적용하고, 경고가 어떻게 표시되는지 확인하는 흐름을 익힌다.

[그림 예정: Alignment Properties의 Design Criteria 탭]

#### 3.3 기준 미달 경고 수정

곡선 반경이 기준보다 작으면 Civil 3D는 경고 아이콘을 표시한다.  
이 경고는 단순 표시가 아니라 설계 검토 신호다.

수정 방법은 보통 다음과 같다.

- 곡선 반경을 키운다.
- IP 위치를 이동해 선형을 완만하게 만든다.
- 설계속도 또는 도로 등급 기준이 맞는지 다시 확인한다.

중요한 것은 경고를 없애는 것이 아니라,  
왜 기준에 미달했는지 이해하고 설계 의도에 맞게 조정하는 것이다.

### 4. 지표면 종단을 추출한다

#### 4.1 Surface Profile의 역할

평면 선형을 만들었다면 기존 지형의 높낮이를 확인해야 한다.  
이를 위해 `Surface Profile`을 생성한다.

Surface Profile은 선형을 따라 기존 지형을 잘라낸 종단선이다.  
도로 중심선을 따라 지형이 어떻게 올라가고 내려가는지 보여준다.

#### 4.2 지표면 종단 생성

지표면 종단은 다음 위치에서 만든다.

**Home 탭 -> Create Design -> Profile -> Create Surface Profile**

작업 순서는 다음과 같다.

1. 기준 Alignment를 선택한다.
2. 기존 지형 Surface를 선택한다.
3. `Add`를 눌러 지표면 종단을 추가한다.
4. 필요하면 좌우 Offset 종단도 추가한다.
5. `Draw in Profile View`를 눌러 종단 뷰를 배치한다.

[그림 예정: Create Surface Profile 대화상자]

#### 4.3 Offset 종단을 함께 추출하는 이유

중심선 종단만 보면 도로 중심부의 높낮이만 알 수 있다.  
하지만 실제 도로 설계에서는 좌우 지형 차이가 중요하다.

예시:

- 중심선: `0.00m`
- 좌측: `-5.00m`
- 우측: `+5.00m`

Offset 종단을 보면 다음을 미리 판단할 수 있다.

- 한쪽으로 지형이 급하게 떨어지는지
- 옹벽이 필요한지
- 배수 방향이 자연스러운지
- 코리더 법면 연결이 어려울지
- 절성토 차이가 크게 발생할지

[그림 예정: 중심선 종단과 좌우 Offset 종단이 함께 표시된 화면]

### 5. 계획 종단을 작성한다

#### 5.1 계획 종단의 의미

기존 지형 종단을 확인했다면 이제 계획 종단을 작성한다.  
계획 종단은 도로의 최종 중심선 높이를 결정하는 설계선이다.

Civil 3D에서는 이를 `Layout Profile` 또는 `Design Profile`로 작성한다.

#### 5.2 Profile Creation Tools 실행

계획 종단은 다음 위치에서 작성한다.

**Home 탭 -> Create Design -> Profile -> Profile Creation Tools**

작업 순서는 다음과 같다.

1. 종단 뷰를 선택한다.
2. 계획 종단 이름을 입력한다.
3. 스타일을 선택한다.
4. 레이블 세트를 선택한다.
5. `Profile Layout Tools`에서 계획선을 작성한다.

계획 종단 이름 예시:

- `ROAD_A_FG`
- `MAIN_ROAD_DESIGN_PROFILE`
- `FG_CENTERLINE`

[그림 예정: Profile Creation Tools에서 계획 종단 이름과 스타일을 지정하는 화면]

### 6. PVI와 종곡선을 이해한다

#### 6.1 PVI의 역할

계획 종단은 PVI와 직선 경사, 종곡선으로 구성된다.

- `PVI`: 종단 경사가 바뀌는 점
- `Grade`: 종단 경사
- `Vertical Curve`: 경사가 갑자기 꺾이지 않도록 연결하는 곡선
- `Crest Curve`: 볼록 종곡선
- `Sag Curve`: 오목 종곡선
- `K-value`: 경사 변화량 대비 종곡선 길이

입문자는 처음부터 K값을 수식으로 외우기보다,  
PVI를 배치하고 종곡선을 넣으면 주행 흐름이 부드러워진다는 개념부터 이해하면 된다.

#### 6.2 계획 종단 작성 흐름

계획 종단은 다음 순서로 작성한다.

1. 기존 지형 종단을 확인한다.
2. 시작점과 끝점의 계획고를 정한다.
3. 중간 PVI를 배치한다.
4. 절토와 성토가 지나치게 치우치지 않게 경사를 조정한다.
5. 각 PVI에 종곡선을 적용한다.
6. K값과 곡선 길이를 확인한다.
7. 종단 밴드에 계획고가 정상 표시되는지 확인한다.

계획 종단은 한 번에 완성되지 않는다.  
지형, 토공량, 접속도로, 배수 조건을 보면서 여러 번 조정한다.

[그림 예정: 기존 지형 EG 위에 계획 종단 FG가 작성된 화면]

### 7. 종단 밴드를 설정한다

#### 7.1 Data Band의 역할

종단 뷰 아래쪽의 표 형태 영역을 `Data Band`라고 한다.  
밴드는 단순 장식이 아니라 설계 데이터를 도면에서 읽을 수 있게 해주는 장치다.

밴드에는 보통 다음 정보가 들어간다.

- 측점
- 지반고
- 계획고
- 절성토고
- 종곡선 제원
- 경사 정보

#### 7.2 Profile View Properties에서 밴드 수정

밴드는 다음 순서로 수정한다.

1. 종단 뷰를 선택한다.
2. 마우스 오른쪽 버튼을 누른다.
3. `Profile View Properties`를 선택한다.
4. `Bands` 탭으로 이동한다.
5. 필요한 밴드를 추가하거나 삭제한다.
6. 각 밴드의 데이터 소스를 지정한다.

[그림 예정: Profile View Properties의 Bands 탭 화면]

#### 7.3 지반고와 계획고 데이터 소스 지정

밴드에서 가장 중요한 것은 데이터 소스다.  
스타일이 맞아도 `Profile 1`, `Profile 2`가 잘못 지정되면 엉뚱한 숫자가 표시된다.

예시:

| 밴드 항목 | Profile 1 | Profile 2 |
|---|---|---|
| 지반고 | EG | 없음 |
| 계획고 | FG | 없음 |
| 절성토고 | EG | FG |

절성토고는 보통 기존 지반과 계획 종단의 차이로 표시한다.  
따라서 EG와 FG가 정확히 연결되어 있어야 한다.

[그림 예정: 밴드별 Profile 1, Profile 2를 지정하는 화면]

### 8. 수직 편각 표현식을 검토한다

#### 8.1 표현식의 필요성

종단 변화점에서 수직 편각을 표시해야 하는 경우가 있다.  
이때 Civil 3D의 `Expression`을 사용할 수 있다.

개념식은 다음과 같다.

`ATAN({Grade In}) - ATAN({Grade Out})`

이 식은 들어오는 경사와 나가는 경사의 각도 차이를 계산하는 방식이다.

#### 8.2 적용 시 주의사항

표현식은 회사 템플릿과 레이블 스타일에 따라 표시 형식이 달라질 수 있다.  
따라서 실제 적용 전에는 다음을 확인한다.

- 경사 단위가 맞는가
- 각도 표시 단위가 맞는가
- 레이블 스타일에서 표현식을 불러오는가
- KDS 기준 표현 방식과 맞는가

[그림 예정: Label Style Composer 또는 Expression 설정 화면]

### 9. 마무리

2개월차의 핵심은 선형과 종단을 따로 배우는 것이 아니다.

- 선형은 도로의 평면 기준이다.
- 종단은 도로의 높이 기준이다.
- Surface Profile은 기존 지형을 읽는 과정이다.
- Layout Profile은 계획고를 정하는 과정이다.
- Data Band는 설계 결과를 도면으로 읽게 해주는 장치다.

> 2개월차의 목표는 선형을 그리는 것이 아니라, **기준선과 계획고를 서로 연결해 코리더를 만들 준비를 끝내는 것**입니다.
