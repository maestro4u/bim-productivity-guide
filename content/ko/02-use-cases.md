# 02. 무엇을 할 수 있나

> 초기에 바로 효과가 나는 업무부터 우선순위를 정리합니다.

---

## 바로 효과가 나는 업무

- 선택 객체 길이 합산
- 해치 면적표 생성
- 다중 스타일 일괄 변경
- 블록 속성값 정리
- CSV 기반 지표면 생성
- 선형/형상선 데이터 추출

## 팀에서 흔한 사용 시나리오

| 업무 | 기대 효과 |
|---|---|
| 반복 산출 | 산출 시간 감소 |
| 도면 정리 | 표준화 향상 |
| 샘플 수정 | 재사용성 향상 |
| 보고용 자료 | 정리 속도 향상 |

## 추천 우선순위

1. 하루에 여러 번 하는 일
2. 실수하면 다시 확인해야 하는 일
3. 표준 규칙이 있는 일
4. 팀원끼리 같은 방식으로 해야 하는 일

> **목표**는 멋진 자동화가 아니라, **매일 쓰는 업무를 가볍게 만드는 것**입니다.
