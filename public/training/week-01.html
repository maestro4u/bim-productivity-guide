01 / UNDERSTAND

만든 지표면, 바로 사용해도 될까요?

생성된 형상에서 설계 판단에 영향을 주는 오류를 먼저 찾습니다.

항측도면에서 지표면을 만들더라도 외곽 경계나 도로·수로 주변의 연결은 확인해야 합니다. 삼각망이 연결되는 방식에 따라 단면과 경사, 물이 흐르는 방향이 달라질 수 있습니다.

  • 01경계 밖 연결 — 외곽으로 길게 뻗은 삼각형
  • 02지형의 꺾임 누락 — 도로·수로 가장자리의 연결
  • 03표고 이상 — 주변과 다른 국부적인 돌출
그림 01-1. 검토가 필요한 삼각망의 예 · 설명용 개념도
오늘의 판단 기준　보기 좋은 지형보다 원자료에 근거한 지형이 중요합니다. 실제 지반고를 확인할 수 없는 곳은 임의로 보정하지 않고 확인 필요 구간으로 남깁니다.
02 / WORKFLOW

오늘의 작업, 다섯 단계

각 단계를 확인한 뒤 Civil 3D에서 함께 진행합니다.

AI와 함께 수행
01

좌표설정하기(GRS80, Bessel)와 작업 조건 확인

작업본을 준비하고 좌표계·단위·등고선 표고·사용할 경계를 확인합니다.

확인할 항목 펼치기
  1. 원본은 보관하고 실습용 작업본을 만듭니다.
  2. 도면 단위와 좌표계를 제공 성과와 대조합니다.
  3. 등고선의 Z값과 표고 표기가 일치하는지 대표 위치에서 확인합니다.
  4. 표고가 없는 객체나 중복 선은 확인 대상으로 분리합니다.
02

TIN 지표면 생성

표고가 확인된 등고선과 필요한 형상으로 지표면을 구성하고 외곽 경계를 적용합니다.

확인 → 사용한 원자료 · 적용 경계 · 표고 범위
03

문제 구간을 찾고 AI와 수정

경계·브레이크라인을 우선 검토하고, 필요한 구간의 삼각망 편집 방법을 판단합니다.

AI 작업지시 예시 · ASTRA / MEDIUM
작업본의 [지표면 이름]에서 [검토 구간]을 확인해줘.
1. 경계 밖 연결과 브레이크라인 누락 후보를 먼저 정리해줘.
2. 원자료와 비교해 수정 근거와 적용할 방법을 제시해줘.
3. 근거가 확인된 항목을 지원되는 도구로 수정하고 재작성해줘.
4. 수정 전후의 대표 표고·단면과 변경 내역을 정리해줘.
표고 근거가 없는 부분은 임의 수정하지 말고 확인 대상으로 남겨줘.
확인 → 수정 근거 · 주변 형상의 영향 · 재작성 결과
AI가 실행하지 못하는 작업은 어떻게 하나요?
실제 연결에서 지원되는 편집 기능을 먼저 확인합니다. 지원되지 않으면 AI가 정리한 수정 위치와 방법을 바탕으로 Civil 3D에서 수행하고, 결과를 다시 비교합니다.
04

경사와 배수 방향 비교

같은 위치에서 수정 전후 단면과 경사·물흐름을 확인합니다. 달라진 부분의 원인을 설명합니다.

확인 → 비교 위치와 배율 통일 · 새로 발생한 오류
05

작업 결과와 확인 사항 공유

작업본, 수정 전후 화면, 변경 내역을 정리합니다. 아직 판단하지 못한 구간도 함께 표시합니다.
