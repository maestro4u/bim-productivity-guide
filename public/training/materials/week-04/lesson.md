# 4주차 — 옹벽 · Dynamo


강의안 v1 · 2026-09-27


기준선과 상하단고를 입력으로 사용해 표준 옹벽을 배치하고 높이 변경과 수량을 검토합니다.


## 잠정 교육일정 (한국시간)

A회차 · 2026-10-22 (목) 13:30~15:30 · 공동연차 조정


## 학습 목표

- 기준선·상하단고 정의

- Dynamo 입력과 결과 이해

- 높이 변화·수량 검증


## 범위

검토된 표준형의 배치·변경 실습입니다. 옹벽 구조해석과 안정 검토를 완료하는 과정은 아닙니다.


## 준비 자료

- 옹벽 표준형과 치수표: 검토된 형식·기초 포함 여부·단위

- 배치 기준선·상하단고: 구간·진행 방향·옹벽 면 방향

- 검증된 Dynamo 그래프: Civil 3D/Dynamo 버전·패키지·입력 정의


## 핵심 개념


### 높이의 기준을 구별

노출 높이, 전체 벽체 높이, 기초 저면고는 서로 다릅니다. 입력표가 어떤 기준을 뜻하는지 정한 뒤 모델 치수와 연결합니다.


### 그래프는 반복 절차

입력 객체·숫자 → 형상 생성 → 속성 부여 → 결과 목록의 흐름으로 읽습니다. 노드를 전부 외우기보다 어떤 입력이 어떤 결과를 바꾸는지 확인합니다.


### 재실행과 객체 중복

그래프마다 기존 객체를 수정하거나 새로 생성하는 방식이 다릅니다. 첫 실행 결과의 ID와 개수를 기록한 뒤 반복 실행 결과를 비교합니다.


## A회차 — 옹벽 배치와 높이 변경

2026-10-22 (목) 13:30~15:30 · 공동연차 조정 · 잠정 / 한국시간

120분: 소개 10 / 조건 15 / 시연 40 / 변경 실습 35 / 결과 검토 15 / 정리 5


### 1. 입력 조건을 표로 정리

상하단고가 뒤바뀌면 높이가 음수가 됩니다.

- 기준선 진행 방향과 앞면 방향을 확인합니다.

- 구간별 상단·하단·기초고와 치수를 표에 기입합니다.

- ID·재료·단위·수량 포함 부위를 정의합니다.

확인: 높이 정의·단위·방향 확인


### 2. 작은 구간에서 Dynamo 실행

전체 옹벽 전에 대표 구간으로 입력을 검증합니다.

- Player에서 그래프와 대상 객체를 선택합니다.

- 객체 유형과 필수 입력이 맞는지 직접 확인합니다.

- 대표 구간을 실행하고 출력 메시지·생성 개수·위치를 봅니다.

확인: Run Complete만으로 형상 적합을 판단하지 않음


### 3. 높이 변화와 지형 접속 검토

계단식·연속식 등 제공 형식의 연결 방식을 유지합니다.

- 전체 구간에 적용하고 높이가 변하는 경계를 확인합니다.

- 기초·벽체의 겹침과 공백, 지형 접속을 단면으로 봅니다.

- ID별 연장과 체적을 추출해 단위와 포함 부위를 확인합니다.

확인: 구간 경계의 겹침·공백·면 방향


### 4. 조건 변경 후 결과 비교

하나의 입력 변경이 어디까지 반영되는지 봅니다.

- 지정 구간 상단고만 변경합니다.

- 그래프 재실행 후 기존 객체와 신규 객체를 구별합니다.

- 높이·체적·객체 개수의 전후 비교표를 만듭니다.

확인: 중복 생성 없이 의도한 구간만 변경


### AI 작업지시

[그래프]의 입력과 출력, 재실행 시 객체 처리 방식을 먼저 설명해줘.
[기준선/상하단고 표]로 대표 구간을 실행하고 ID·개수·높이·체적을 확인해줘.
[구간]의 상단고만 [값]으로 변경해 전후를 비교해줘.
지원되지 않는 노드나 누락 패키지는 정확히 기록하고 임의로 대체하지 마.


## 교육용 사례

벽체 체적을 단순 형상으로 검산

교육용 직육면체 벽체의 두께 0.30m, 높이 2.00m, 길이 10.00m. 기초와 개구부는 없습니다.

체적은 0.30 × 2.00 × 10.00 = 6.00m³입니다. 3.00m 높이로 바꾸면 9.00m³입니다. 실제 옹벽은 단면 변화·기초·겹침을 별도로 반영하므로 이 산식은 단순 형상 검산용입니다.


## 자주 발생하는 문제

- 옹벽이 반대 방향에 생성됨: 기준선 방향과 프로파일 배치 좌표계를 확인합니다.

- 재실행마다 수량이 증가함: 기존 객체 수정인지 추가 생성인지 확인하고 중복 ID를 조사합니다.
