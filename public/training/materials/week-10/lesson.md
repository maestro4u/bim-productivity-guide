# 10주차 — BIM 도면 작성

라벨·종단밴드·출력양식을 적용하고 모델의 변경이 도면에 올바르게 표현되는지 확인합니다.

A회차 · 2026-12-04 (금) 13:30~15:30


## 학습 목표

- 객체와 라벨 연결

- 밴드의 데이터 원본 지정

- BIM 도면 출력과 대조


## 범위

제공 스타일과 출력양식을 적용·부분 수정합니다. 모든 스타일을 새로 개발하거나 발주처 전체 납품을 완료하는 범위는 아닙니다.


## 준비 자료

- 9주차까지의 검토 모델: 평면·종단·시설물의 현재 버전

- 회사 출력양식·스타일·밴드세트: 도곽·축척·문자·CTB/STB 등 제공 설정

- 발주 BIM 도면 체크리스트: 객체 분류·표기·파일 및 제출 요구사항


## 핵심 개념


### 표시 오류와 모델 오류

잘못된 숫자를 발견하면 객체 값, 표시할 속성, 단위/반올림, 스타일 순서로 확인합니다. 라벨 문구만 덮어써서 원본 오류를 숨기지 않습니다.


### 밴드는 데이터 원본을 참조

같은 밴드 스타일도 Profile 1/2와 관망·횡단 자료 지정이 다르면 다른 값을 보여줍니다. 밴드의 이름보다 실제 참조 객체를 확인합니다.


### 도면과 BIM의 일치

출력은 모델의 검토 결과를 전달합니다. 표기·도면번호·개정정보·공종 속성의 일치를 확인하고 제출 형식은 제공 발주 기준에 맞춥니다.


## A회차 — 라벨·밴드·출력 검증

2026-12-04 (금) 13:30~15:30 · 잠정 / 한국시간

120분: 소개 10 / 조건 15 / 시연 40 / 변경 실습 35 / 결과 검토 15 / 정리 5


### 1. 도면과 모델의 연결 목록 작성

무엇을 어느 도면에 표현할지 정합니다.

- 도면번호·시설·모델 버전을 목록으로 만듭니다.

- 표현할 객체 속성과 표시 단위를 정합니다.

- 제공 템플릿과 출력 설정을 작업본에 적용합니다.

확인: 도면/모델 버전·표기 대상 일치


### 2. 라벨을 적용하고 대표 값 확인

표시만 보고 맞다고 판단하지 않습니다.

- 선형·종단·관망 등 대상에 라벨을 적용합니다.

- 객체 속성 창과 라벨의 값·단위·정밀도를 대조합니다.

- 겹친 라벨은 배치와 스타일로 정리합니다.

확인: 표시값·원본값·반올림 규칙


### 3. 종단밴드 데이터 원본 지정

원지반과 계획종단을 뒤바꾸지 않습니다.

- 종단뷰 Bands 설정에서 제공 밴드세트를 적용합니다.

- Profile 1/2와 필요한 관망·횡단 데이터 원본을 지정합니다.

- 시점·중간·종점 측점에서 표고와 표기를 대조합니다.

확인: 밴드 타입과 실제 참조 객체


### 4. 모델 한 값을 바꿔 갱신 검증

연동되지 않는 수동 표기를 찾아냅니다.

- 검토용 사본에서 대표 계획고 또는 관저고를 변경합니다.

- 라벨·밴드와 관련 도면의 갱신 상태를 봅니다.

- 연동되지 않는 표기는 원인을 기록하고 결과를 복구/정리합니다.

확인: 수동 문구와 연동 속성 구별


### 5. PDF·DWG 결과 대조

화면에서 보이던 내용이 출력에도 있어야 합니다.

- 제공 축척·용지·문자·선가중치 설정으로 출력합니다.

- 잘림·글꼴 대체·선종류·가독성과 도면번호를 확인합니다.

- 모델 검토 목록과 제출 체크리스트를 첨부합니다.

확인: 모델과 PDF의 대표 값 일치


### AI 작업지시

[도면 목록/제공 양식]을 기준으로 라벨·밴드·출력 설정을 정리해줘.
밴드의 Profile 1/2 및 데이터 원본을 실제 객체 이름으로 확인해줘.
대표 측점의 원본 값과 표시값을 비교하고 차이는 단위·정밀도·참조 오류로 구분해줘.
모델 값을 바꾸지 않고 표기만 덮어쓰는 방식은 제안하지 마.


## 교육용 사례

밴드의 지반고와 계획고 확인

교육용 동일 측점의 원지반고는 30.00m, 계획고는 31.20m입니다.

계획고−원지반고는 +1.20m입니다. 밴드에 −1.20m가 나타나면 차이의 정의와 Profile 1/2 연결을 확인합니다. 부호를 수동으로 바꾸기 전에 양식이 요구하는 계산 방향을 확인합니다.


## 자주 발생하는 문제

- 밴드는 있는데 값이 비어 있음: 참조 종단의 범위, 데이터 원본, 표시 위치를 확인합니다.

- PDF에서 문자나 선이 사라짐: 플롯 레이어·출력 스타일·글꼴·뷰포트 설정을 확인합니다.
