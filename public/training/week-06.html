01 / UNDERSTAND

먼저 이해할 세 가지

작업을 시작하기 전에 입력과 결과의 관계를 짚습니다.

건축 기준고와 대지 계획고

건축물의 0.000이 절대 표고와 어떻게 연결되는지 먼저 확인합니다. 화면에서 바닥이 땅에 닿는 것만으로 출입구 접속과 배수를 판단하지 않습니다.

사면은 기준선과 목표의 관계

사면 시작 형상과 표고, 기울기 표기, 소단, 접속할 지표면을 정합니다. 1:n 비율과 퍼센트 경사는 같은 숫자를 넣을 수 없습니다.

가시설은 시공 단계로 구분

완성 상태만 보면 굴착 중의 간섭을 놓칩니다. 표준 가시설과 제공 굴착 단계를 분리 표시하고 각 단계의 모델 범위를 확인합니다.

수업 전 준비

제공 건축물 모델
삽입점·단위·진북/프로젝트 북·기준고
계획면·사면 조건표
시작선·표고·경사 표기·소단·접속면
가시설 표준형·단계표
검토된 치수·근입·굴착 범위와 시공 순서
이번 강의의 범위
제공 건축물과 검토된 가시설 표준형의 배치·단계 검토입니다. 건축 설계 전체와 가시설 구조·지반 안전성 판단을 대신하지 않습니다.
최초 시연 Astra medium반복 실습 Sol medium확인된 결과 요약 Luna low

모델 설정은 권장 시작값입니다. 반복 실습은 검증된 도구·그래프를 재사용하며, 현재 연결에서 지원되지 않는 기능은 실제 프로그램에서 수행하고 결과를 대조합니다.

  2. 건축 기준고를 대지 절대 표고와 연결합니다.

  2. 제공 사면 조건의 비율·방향·소단을 적용합니다.
  3. 목표 지표면까지의 접속과 겹친 구간을 확인합니다.

가시설과 굴착 조건 구분

부재 치수와 굴착 단계를 서로 다른 입력으로 관리합니다.

  1. 제공 흙막이/가시설 표준형의 방향과 치수를 확인합니다.
  2. 굴착 경계와 단계별 굴착고를 표로 만듭니다.

02

대표 구간 배치 후 전체 적용

반복 배치의 방향과 개수를 먼저 확인합니다.

  1. 기준선을 따라 표준 부재를 배치합니다.
  2. 대표 단면에서 근입·상단고 등 제공 치수를 확인합니다.
  3. ID와 단계 속성을 부여하고 중복 여부를 확인합니다.
확인 → 모델 치수가 제공 조건과 일치
03

단계별 굴착·간섭 검토

단계마다 보이는 객체와 적용 지표면을 고정합니다.

  1. 단계별 표시 집합을 만듭니다.
  2. 건축물·사면·가시설·굴착면을 같은 단면에서 비교합니다.
  3. 굴착량을 산출할 때 중복 영역과 기준면을 기록합니다.
확인 → 단계 간 수량과 누적 수량 구분

형상 오류와 별도 설계 검토를 구별합니다.

  1. 조건 하나를 변경하고 영향을 받은 객체를 표시합니다.
  2. 단계별 수량 및 간섭 후보를 정리합니다.
  3. 제공 설계조건으로 해결되지 않는 항목을 남깁니다.

GUIDED EXERCISE

모델이 1,000배 커 보이는 이유

건축물에서 10,000mm로 주어진 길이를 Civil 3D 미터 작업본으로 옮깁니다.

생각해 본 뒤 해설 보기

길이는 10m입니다. 단위 변환이 이미 적용된 가져오기 결과에 다시 0.001 축척을 적용하면 이중 변환입니다. 먼저 모델의 실제 측정 길이를 확인한 뒤 한 번만 변환합니다.

사면이 반대 방향으로 생성됨

기준선 방향과 절토/성토 측, 목표면 위치를 확인합니다.

단계별 굴착 합계가 과다함

누적 체적을 단계 증가분으로 다시 더했는지 확인합니다.

화면의 체크는 자가 확인용이며 저장·공유되지 않습니다. 기록을 남길 때는 검토표를 내려받으세요.
