01 / UNDERSTAND

먼저 이해할 세 가지

작업을 시작하기 전에 입력과 결과의 관계를 짚습니다.

선형 위치와 구조물 좌표

교량 중심선의 측점·편거·회전과 교량 기준고를 같이 관리합니다. 위치만 맞고 회전이나 표고가 다르면 도로와 접속되지 않습니다.

부재별로 나누어 관리

상부공·교대·교각을 각각 식별해 배치표와 연결합니다. 한 덩어리 형상만 있으면 부재별 수량과 변경 추적이 어려워집니다.

형상 생성과 구조설계

이 강의는 승인된 교량 형식·치수를 모델에 반영합니다. 부재 위치가 바뀔 때 구조적 검토가 필요한 사항은 별도 쟁점으로 기록합니다.

수업 전 준비

도로 선형·종단

경간 구성·폭·교각/교대 위치·치수·기준고
제공 형상 라이브러리·Dynamo

02 / WORKFLOW

오늘의 작업 순서

강사 설명 뒤 실제 프로그램에서 실행하고 조건 하나를 바꿔 비교합니다.

SESSION A

교량 부재 배치

소개 10분 · 조건 15분 · 시연 40분 · 변경 실습 35분 · 결과 검토 15분 · 정리 5분

120분
01

교량 배치 기준 확정

부재의 위치를 재현 가능한 값으로 정리합니다.

  1. 교량 시종점 측점과 도로 기준고를 기록합니다.
  2. 교량 축·사각·횡단 방향의 정의를 확인합니다.
  3. 부재 ID별 위치와 치수표를 준비합니다.
확인 → 좌표·방향·표고 기준 하나로 통일
02

상부공의 기준 형상 생성

완성 교량 전에 상부공과 도로의 관계를 봅니다.

  1. 제공 표준형에 폭·길이·기준고를 입력합니다.
  2. 시점·종점과 중간의 기준 위치를 대조합니다.
  3. 단면과 도로 계획고의 높이 관계를 확인합니다.
확인 → 상부공 기준면과 노면고를 혼동하지 않음
03

교대·교각을 ID별 배치

같은 형식의 반복 배치에 Dynamo를 적용합니다.

  1. 부재표의 위치·회전·높이를 입력합니다.
  2. 대표 부재 1개를 확인한 뒤 반복 실행합니다.
  3. 교각/교대 개수와 부재 ID 목록을 비교합니다.
확인 → 부재 누락·중복·회전 오류
04

부재 관계와 전달 정보 정리

Revit 활용에 필요한 정보를 미리 분리합니다.

  1. 접속부와 상하부공의 공간 관계를 단면으로 봅니다.
  2. 형상 파일과 치수·재료·ID 데이터를 구분합니다.
  3. 11주차에 사용할 대표 부재 하나를 지정합니다.
확인 → 형상과 부재표가 같은 버전인가
A회차 AI 작업지시 · Astra medium
[교량 조건표]를 기준으로 좌표·기준고·회전 정의를 먼저 정리해줘.
제공 표준형을 [그래프/지원 도구]로 배치하고 부재 ID와 위치 목록을 출력해줘.
새 부재 형식을 임의 설계하지 말고 도로 접속부 및 누락·중복 후보를 표시해줘.

대괄호 안에는 실제 파일·객체·조건을 넣습니다. 실행 여부와 검증 결과를 함께 기록하세요.

SESSION B

위치 변경과 접속 검토

소개 10분 · 조건 15분 · 시연 40분 · 변경 실습 35분 · 결과 검토 15분 · 정리 5분

120분
01

변경 조건과 영향 범위 지정

여러 변수를 한꺼번에 바꾸면 원인을 찾기 어렵습니다.

  1. 대안 A를 저장합니다.
  2. 교육 조건표에서 교각 1개 위치 변경량을 정합니다.
  3. 관련 상부공·하부공·기초와 간섭 검토 대상을 표시합니다.
확인 → 변경 대상과 고정 조건 명시
02

그래프로 변경 실행

단순 평행 이동과 관계를 유지하는 재생성을 구별합니다.

  1. 기존 ID를 기준으로 수정 방식과 재실행 동작을 확인합니다.
  2. 조건을 변경하고 결과 목록을 추출합니다.
  3. 원래 모델의 잔여 객체나 중복을 검사합니다.
확인 → 변경 후 ID/부재 개수 대조
03

도로 접속·공간 여유 비교

변경된 부재와 주변 시설의 관계를 확인합니다.

  1. 시종점 단면과 교각 주변 단면을 비교합니다.
  2. 제공된 공간 여유 기준에 따라 간섭 후보를 정리합니다.
  3. 확정하지 못한 구조적 조건은 검토 필요로 기록합니다.
확인 → 무간섭과 구조 적합을 동일시하지 않음
04

수량과 인계 데이터 저장

후속 활용에 필요한 단위와 출처를 남깁니다.

  1. 부재별 형상 수량을 기존 대안과 비교합니다.
  2. 위치만 바꾼 부재의 치수까지 달라졌는지 확인합니다.
  3. ID·형상·치수표·변경 이유를 한 묶음으로 저장합니다.
확인 → 11주차 재현에 필요한 자료 포함
B회차 AI 작업지시 · Astra medium
대안 A를 보존하고 [교각 ID]의 위치만 [변경량] 이동하는 대안 B를 적용해줘.
관련 부재의 ID·좌표·치수·수량과 도로 접속 상태를 비교해줘.
변경하지 않은 부재가 바뀌거나 수량이 달라졌다면 원인을 분리해 설명해줘.

대괄호 안에는 실제 파일·객체·조건을 넣습니다. 실행 여부와 검증 결과를 함께 기록하세요.

03 / PRACTICE & REVIEW

아래 사례는 원리와 검산 연습을 위한 가상 조건입니다.

GUIDED EXERCISE

위치만 바꿨는데 체적이 달라졌다면?

치수·형상·겹침 처리가 동일한 단일 부재를 평행 이동합니다.

생각해 본 뒤 해설 보기

단순 위치 이동만으로 개별 부재의 기하학적 체적은 변하지 않습니다. 변화가 있으면 치수 입력, 자동 높이 갱신, 중복 생성, Boolean 처리 여부를 확인합니다. 주변과의 접속이나 간섭은 달라질 수 있습니다.

부재가 회전해 배치됨

축 방향·사각 정의·각도 단위를 확인합니다.

Revit에서 수정이 안 됨

참조 형상인지 네이티브 패밀리인지 구분하고 11주차 매핑으로 연결합니다.

화면의 체크는 자가 확인용이며 저장·공유되지 않습니다. 기록을 남길 때는 검토표를 내려받으세요.
