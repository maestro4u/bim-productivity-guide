# BIM Productivity

Civil 3D + Dynamo 기반 반복 설계업무 줄이기 가이드입니다.

## 구조

- `/ko`: 한국어 가이드
- `/en`: 영어 가이드
- `src/app/[lang]/page.tsx`: 언어별 본문 렌더링
- `src/components/*`: 상단 네비게이션, 히어로, 사이드바, 섹션 블록
- `content/`: 섹션별 Markdown 원문

## 배포

이 저장소는 GitHub Pages workflow로 정적 export 됩니다. 커스텀 도메인은 `bim.maestro4u.kr`입니다.
